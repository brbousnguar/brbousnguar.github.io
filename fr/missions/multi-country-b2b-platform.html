Mission client

Une plateforme de commerce B2B pour plus de 15 pays

Piloter la migration d'un groupe de chimie de spécialité de SAP Hybris 6.7 vers Commerce Cloud, avec des données ERP en temps réel

La mission

Client
Un groupe de chimie de spécialité
Période
2018 – 2021
Mon rôle
Lead technique, SAP Commerce Cloud
Stack
SAP Commerce Cloud · SAP ERP · OCC APIs · Spring

Une plateforme B2B vieillissante sous SAP Hybris 6.7, incapable de suivre un déploiement multi-pays ou de passer en headless.

En tant que lead technique, j'avais la main sur l'architecture et la migration vers SAP Commerce Cloud (CCv2) : une seule plateforme pour tous les pays, alimentée en temps réel par l'ERP.

La forme

Canaux

Vitrines B2B

  • 15+ pays
  • Headless
⇄

Cœur commerce

SAP Commerce Cloud

  • CCv2
  • API OCC sur mesure
  • Workflows B2B
⇄

Back-office

SAP ERP · partenaires

  • Prix, stocks, commandes
  • Logistique tierce
  • Prestataires de paiement

Ce que j'ai construit

  • L'architecture et la migration de SAP Hybris 6.7 vers Commerce Cloud CCv2.
  • Les intégrations SAP ERP pour les prix, les stocks et les commandes, plus la logistique tierce et les prestataires de paiement.
  • Des API OCC sur mesure pour les workflows B2B headless.
  • Du travail de performance et de SEO technique pour le trafic organique.

J'ai aussi formé les développeurs juniors à SAP Commerce, Spring et aux patterns d'intégration.

Le résultat

Une seule plateforme B2B pour plus de 15 pays, avec des données ERP en temps réel et du commerce headless.
